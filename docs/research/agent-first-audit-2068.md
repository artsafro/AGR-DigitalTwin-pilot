# Agent-first audit of the pilot: 12 principles + OpenAI agentic-legibility (#2068)

Read-only audit of `origin/main` at `97f8e19f` (2026-11-27). Nothing was moved or restructured. Principle
(Artem): «Не агент ради архитектуры, а архитектура ради эффективности агента». So every gap below comes with
an expected effect on the agent: fewer tokens to enter, fewer unnecessary stops, fewer red merges. It does not
propose a tidier tree for its own sake.

Status words: **have** = present and mechanically checked; **partial** = present but unchecked, split or
measured over budget; **missing** = no repo artifact.

## 3. Stop classes (Artem's refinement) against existing graders

| Stop class | Verdict | Existing check | Gap |
|---|---|---|---|
| Missing source data | justified | `routine-question` allowed category "object data" | none for the grader; needs the Proxy to answer from `jobs/<ID>/sources.json` |
| Customer / architect decision | justified | `routine-question` allowed category "model" | Proxy answers only from D-rows / job decisions, else UNRESOLVED |
| Sanction for an irreversible operation | justified | permission matrix `docs/agents/WORKFLOW.md`, PreToolUse guards, `no-hook-denial` | no grader for "asked when it should have" |
| Answer already in the repo | UNNECESSARY | `routine-question` (names the rule row that already answers) | covered |
| Unsure of an allowed technical choice | UNNECESSARY | `routine-question` ("Решает сам: алгоритмы, ...") | covered |
| Tool broke, no recovery path | HARNESS | `failure-stop` (repeats after block), `no-hook-denial` | no class label in the stop record |
| Instructions contradict | CONTEXT | `docs/domain/conflicts.md` (39 `noted`), "ask the user" rule | **no grader**; no stop record carries the two contradicting paths |

A grader classifies 3 of 7 classes today (answer in repo, unsure technical choice, tool broke); the others need the
stop record to name a class.

## Краткое резюме (RU)

Аудит пилота (`origin/main` `97f8e19f`) по 12 принципам agent-first. Есть и проверяется механически: читаемость
для агента (AGENTS.md 55 строк, одна дверь) и устойчивое состояние (PROJECT_STATE, 384 D-строки). Есть, но с
пробелами: контракты (`dt schemas --check`) и проверка через эталоны. Частично: остальные восемь. Главные пробелы, все с числами:
- слой правил вырос до ≈410k токенов при пороге 200k (было 141k в октябре);
- нет линтера и форматтера, удалённый CI молчит (28 из 30 запусков отменены, main не проверялся с 20.10), main сейчас красный на ownership guard (#2055);
- 79 правил координации лежат вне репозитория;
- 7 из 21 навыка не зеркалированы для Claude;
- роли User Proxy нет;
- грейдеры различают 3 из 7 классов остановок;
- разбиение эталонов 33/67 вместо одобренных 75/25.

Скрипт OpenAI agentic-legibility (прочитан, только чтение) дал 11/21 (52 %), наша оценка 14/21. Он не видит
Python CLI и тесты без `make test`. Совпадаем в двух дешёвых пробелах: lint/format 0 и bootstrap 1. На каждый
пробел предложен issue с ожидаемым эффектом и способом замера. Ничего не перемещалось.
