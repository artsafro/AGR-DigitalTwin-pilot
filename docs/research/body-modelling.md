# Чистый бадик: как строить сетку корпуса (#1618)

Кратко для Артёма: эталон G22 (его ручная НПМ) измерен в Blender без окна. Типовые этажи эталона —
**96–98 % квадов на фасаде**, рёбра идут только по границам окон и зон отделки, окна и панели —
**текстура**, модуль этажа повторён **без единого лишнего ребра** (одинаковое число вершин на каждом
уровне). Треугольники живут там, где они ничего не портят: в плоских горизонтальных крышках (план),
у входов первого этажа и на кровле. Отклонённые углы KPP1 v003 — обратный случай: «паутина» из рёбер,
протянутых от проёмов через всю стену. Ниже — 14 правил (BM-01…BM-14), каждое привязано к этапу
скелета, разделу скилла и компоненту метрики #1616. Скруглённых углов в G22 нет: правило скруглений
построено по источникам и переписи участка 63 и требует проверки на учебном полигоне.
Одностраничная сводка: [body-modelling-summary-ru.md](body-modelling-summary-ru.md).

Статус: исследование, не модель и не приёмка. Пороги — **предложение оркестратора, пользователь может
изменить**; ни один порог не становится блокирующим без решения Артёма (как [D227] для #1446).
Правило разреза ОКС (#1613: окна/витражи/кровля/отливы врезаны, цоколь — одним или врезан, стойки и
панели обычно текстурой, решение по проекту с причиной) и [D312] (квады где возможно) здесь
применяются, не меняются. D-строка #1613 ещё не на `main`; ссылка — на задачу.

## 5. Правила

Каждое правило: что делать, почему (источник/измерение), чем проверить.

- **BM-01. Тело — из контура плана этажа.** Контур этажа (стены по уровням [D023]) выдавливается
  на высоту модуля; вершины контура — только в изломах стены и на линиях проёмов/зон. Почему: E2, S1.
  Проверка: вершин контура без излома и без линии (коллинеарные) — 0.
- **BM-02. Горизонтальные петли — только на линиях с причиной:** низ/верх окон, граница зоны
  отделки, пояс, излом. Перекрытие — текстурой, если на нём нет смены материала или объёма.
  Эталон: 2–3 петли на этаж (E2). Проверка: петель на этаж ≤ 3, у каждой — причина.
- **BM-03. Вертикали — кольцами через всю высоту модуля** по откосам окон и стыкам зон (Loop Cut /
  Swift Loop, S7). Шаг вертикалей = шаг фасадного модуля (0,6–1,1 м в эталоне). Проверка: доля квадов
  типового фасада ≥ 0,95 (эталон 0,961–0,982); почти совпадающих вертикалей (< 3 см) — 0 или review.
- **BM-04. Не сваривать то, что врезается.** Окна-витражи, кровля, отливы, цоколь (одним или врезан),
  корзины, козырьки — отдельные оболочки поверх стены; стену под ними не резать (#1613, E4). Проверка:
  число врезанных оболочек и сварок через границу элемента (компонент #1616).
- **BM-05. Петля не уходит за свой элемент.** Разрез ради проёма идёт по кольцу модуля, а не
  «соединением точек» через всю стену (KPP1 v003). Если кольцо не замыкается — элемент врезается
  (BM-04), а не режется. Проверка: веера ≥ 3 треугольников у вершины стены (`body_layout.py`), полюса
  валентности ≥ 6 ≤ 0,5 % вершин фасада (эталон 0,29–0,48 %).
- **BM-06. Диагональ — только где она дешевле петли:** (а) плоская горизонтальная крышка/потолок
  (план), (б) переход плотности на неповторяемом 1-м этаже или верхе, (в) скат кровли/наклонная
  грань, где квад был бы неплоским. Никогда — на типовом фасаде ради «выравнивания» сетки. Эталон:
  треугольники фасада 2–4 % на типовых, 5–35 % на 1-м этаже и верху (E5). Проверка: треугольники
  считаются по полосам; на типовой полосе — review выше 5 %.
- **BM-07. Скругление — по радиусу, а не по Revit.** Сегментов на 90°: наименьшее n, при котором
  стрелка хорды `R·(1−cos(45°/n))` ≤ 2 см, затем подогнать так, чтобы длина сегмента была кратна
  шагу фасадного модуля (вертикаль сегмента = вертикаль текстуры). По стрелке 2 см:
  R 0,5 м → 3; 1 м → 4; 2 м → 6; 3 м → 7; 5 м → 9; 10 м → 13; 20 м → 18. Петли этажа обходят дугу
  кольцом без треугольников. Скругление R < 0,3 м на фасаде — фаской из 2 сегментов или текстурой.
  Почему: S8/S10 (Segments), раздел 3. **Гипотеза:** эталон скруглений не содержит (E8) — проверить
  на учебном полигоне участка 63 и подтвердить у Артёма.
- **BM-08. Декор: объём, видимый в силуэте, — врезанная оболочка; рельеф < ~5 см — текстура.**
  Пояса и карнизы с выносом — отдельные кольцевые элементы; рустовка, панели, стойки — обычно
  текстура со швом (#1613). Почему: S1 (силуэт), E4. Где стойки «геометрией» (#1609 пересобирает
  стойки KPP1 отдельными элементами) — решение проекта с причиной (вопрос в разделе 8).
- **BM-09. Одна плоскость — один набор граней.** Не держать почти совпадающие вершины и рёбра ближе
  3 см (E7); чистить Limited Dissolve с Delimit по материалу/UV (S6), не пересекая границ зон.
  Проверка: щепки < 5° на типовом фасаде ≤ 0,5 % (эталон 0,26–0,65 %), n-гоны 0 ([D312]).
- **BM-10. Модуль этажа — граница по линии окна или перекрытия, где уже есть петля.** Модуль
  строится один раз (сетка, ID, UV), проверяется, затем тиражируется (Array / Clone, S9, S4);
  уникальные 1-й этаж и верх собираются отдельно и стыкуются по общей петле. Проверка: одинаковое
  число вершин на одинаковых уровнях типовых этажей (эталон: 957 × 21).
- **BM-11. ID материалов и UV — на модуле до тиражирования.** ВПМ: зоны отделки = ID (UDIM), шов UV
  на границе зоны и модуля, грань ≤ 3,8–4 м на тайл 4096 (#1616); НПМ: один материал-атлас, плотность
  по регламенту. Эталон НПМ: 1 материал, атлас 2048², UV в [0,1]. Проверка: ID и UV модуля совпадают
  на всех копиях; граней длиннее 3,8 м на фасаде ВПМ — 0.
- **BM-12. Сначала типовой этаж, потом всё остальное.** Порядок: контур → петли модуля → врезанные
  элементы → ID/UV → лист Артёму → тиражирование → 1-й этаж/верх → кровля. Показ модуля до
  тиражирования (task-intake: первый кусок принят — потом остальное).
- **BM-13. Бюджет держит модуль.** Треугольников после экспорта = модуль × этажи + уникальное; если
  модуль × этажи не влезает в 150 000 (НПМ, [D010]), упрощать модуль, а не триангулировать «паутиной».
  Эталон корпуса 1: 148 186 — на пределе.
- **BM-14. Лист сетки до показа.** Wire + текстура одного модуля и одного угла (как
  `g22_etalon_wire_sheet.png`) рядом с эталоном; числа метрики #1616 на листе.
