## Frozen protocol (before scoring)

**H140:** matching 2D line placement, without titles or axes, yields more correct assignments than #139 roofline V1 on KPP1 synthetic partials, with no confident wrong face. This is a candidate for the shared OKS view-to-face map sheet, not a production change.

- Cohort: exact #139 fixtures and independent axis/plan GT, Git `38f7d95ee54a677ac744c0148fb1fce33b06d9d3`; four full KPP1 views and 36 synthetic horizontal crops, four full AC08 views and 36 crops as the symmetric negative. Use the same crop bounds, raster scale, widths and trusted GT joins as #139. Equal denominators are mandatory; GT labels never enter scoring. Neither input preselection nor thresholds may use the results of this round. There are no real untitled or non-axis/inner-corner views in this cohort. Sokolniki #2001 is open and excluded. G22, OBR22, Vatutino and raster PDF not measured.
- Pair A = unchanged #139 V1; B = 2D DXF paths vs orthographic mesh silhouettes, depth discontinuities >0.03 m and >30° normal creases, in both image directions. Align at the top occupied row of each candidate span, searching ±2 rows and the same horizontal offsets as V1. Score the maximum harmonic mean of view-to-model and model-to-view hit fractions within a Chebyshev distance of 2 pixels (0.2 m). Reject empty bands; never add an edge at a synthetic crop boundary. As in #139, accept only score >=0.30 and best-other margin >=0.10. No textures, axes, names, or ground-truth alignment.
- Metric: correct / answered (undefined at zero), with abstain/total and raw counts, separately by project and full/partial view. Recommend B for this fixture only if it gains >=4 correct KPP1 crop assignments over A at the median of 3, retains both labelled long-view V1 positives (1-4 and 4-1), and makes zero wrong assignments across 80 cases in every run. Symmetric AC08 must always abstain. Refuted if measured and it misses any bound. No production adoption from synthetic crops, even on success.
- Separate injected control: horizontal reflection of each full view, with the original physical face ID retained. Count changed pixels per view (`not_exercised` for zero). A confident wrong answer on any exercised reflection rules out applying the method when source handedness is unknown; not pooled with the clean score. Synthetic pure-score witnesses: translated asymmetric pattern preserved within tolerance; displaced pattern outside tolerance worse; distinct candidate yields answer; equal candidates and empty evidence yield abstention. No actual rejected delivery was used; the wrong candidate faces and symmetry are the rejection controls for this assignment task.
- Budget: one new candidate, one baseline, three fresh paired processes (new ray casts and DXF reads, not re-scoring stored projections). After pair 1, proceed only if two more pairs at 2× the first pair's wall time fit in a 15-minute batch including preflight; timeout 300 s per pair. Stop on mismatch, exhausted budget or at pair 3. No threshold/variant adjustment after scoring. Do not edit source files, delivered packages or other cards' tracking files; no shortcuts or test deselection.
