# Чистый бадик — сводка для Артёма (#1618)

**Что сделано.** Твою НПМ G22 (корпуса 1–3) измерил в Blender без окна: треугольники сшил обратно в
квады только там, где пара плоская и прямоугольная (1°), — оставшиеся треугольники и есть диагонали,
которые были тебе нужны. Сделал листы сетки с текстурой и без. Для сравнения взял отклонённые углы
KPP1 v003. По участку 63 посчитал, как Revit отдаёт скругления.

**Что показал эталон.**
- Типовые этажи: на фасаде **96–98 % квадов**, щепок 0,3–0,7 %.
- Окна, рамы, панели — **текстура**; в сетке у окна только его 4 линии.
- Рёбра идут **только по границам окон и зон отделки**: 2–3 горизонтальные петли на этаж (низ/верх
  окна), вертикали по откосам и стыкам зон с шагом 0,6–1,1 м. Линии перекрытия в сетке нет.
- **Модуль этажа повторён точно**: в корпусе 1 по 957 вершин на каждом из 21 уровня.
- Корзины, козырьки — **отдельные врезанные коробки**, стена под ними не разрезана.
- Треугольники есть там, где ничего не портят: плоские крышки и потолки, входы 1-го этажа, кровля.
- Скруглённых углов в G22 нет.
- В KPP1 v003 всё наоборот: рёбра от проёмов протянуты через всю стену, получилась «паутина».

**Правила (14, BM-01…BM-14), коротко.**
1. Тело строится из контура плана; петли ставятся только на линиях, у которых есть причина
   (окно, зона, пояс, излом).
2. Вертикали идут кольцом через весь модуль. Проём режем по кольцу, а не соединением точек через
   стену. Если кольцо не замыкается, элемент врезаем.
3. Окна, витражи, кровлю, отливы, корзины и декор с выносом **врезаем**, а не свариваем. Мелкий
   рельеф, панели, стойки — обычно текстура.
4. Диагональ допустима только на плоской крышке, на неповторяемом 1-м этаже или верхе и на
   наклонной грани. На типовом фасаде её быть не должно.
5. Скругление строим по радиусу, а не по Revit (Revit даёт 26–360 сегментов на 90°). Число
   сегментов берём из стрелки хорды 2 см: R 1 м → 4, 2 м → 6, 5 м → 9, 10 м → 13, затем подгоняем
   к шагу текстуры.
6. Сначала один модуль этажа: сетка, ID, UV, лист тебе. Потом тиражирование, 1-й этаж, верх,
   кровля.

**Нужно твоё решение (3 вопроса).**
1. **Стойки по умолчанию.** Ты сказал «стойки, панели текстурой обычно», а в задаче на метрику
   написано «стойки геометрией». Рекомендую: текстура; геометрия — если стойка видна в силуэте или

2. **Скругления.** Стрелка хорды 2 см и подгонка сегмента к шагу текстуры — так?
3. **Пороги «на проверку».** Типовой фасад ≥ 95 % квадов, щепок ≤ 0,5 % — подходит?
