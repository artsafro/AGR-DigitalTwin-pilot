# Почему агенты строят плохую сетку бадика и как строить чистую по построению (#1742)

Статус: исследование, не модель и не приёмка. Производственные файлы не менялись. Перед #1736.

## 0. Кратко для Артёма

**Почему сетка плохая.** За 14 вердиктов по бадику (6 приёмок, 8 отказов) все 6 принятых тел этапа 1
(G22 к.1/к.2/к.3, 63A, 63C v002, 63B v007) построены одним способом — **решёткой**: кольцо станций по контуру
(углы, откосы, стыки зон) × общие уровни этажа (низ/верх окна, пол), проём = вынутая ячейка + 4 квада откоса на
тех же вершинах, модуль этажа тиражирован. 5 из 6 отказов по сетке — **ремонт чужой сетки или сборка по
кускам**: 63B v004–v006 (свой сборщик поясов/скруглений/рам, чинили по обведённым местам — 3 версии, 4 отказа), KPP1 v003
и v004 (перерезали плоскости триангулированного R1, 1-й этаж не тронули). Шестой (63C v001) — откос построен
вне станций решётки. Правила BM-01…14 написаны как **проверки результата** («квадов ≥ 95 %», «нет вееров»),
поэтому агент выполняет их ремонтом по месту, а проверка смотрит только туда, где был прошлый дефект.
Решётка же даёт чистоту **по построению**: в ней просто нет места для веера, диагонали или несваренного края.

**Измерено** (таблица в §2): у принятых тел 100 % квадов фасада, 0 вееров, 0 диагоналей через стену,
2,1–3,2 глобальных петли на этаж, петли обходят углы (100 %), 0 трещин; у отклонённых — T-трещины (63B v004
256), веера на крышках (63B v005 1 034 треугольника), клинья (63C v001 176, 63B v006 460), 15 664 диагонали и
0 глобальных петель (KPP1 w7). Новый **локальный сигнал по ячейкам** (плоскость фасада × этаж) разделяет все
пары: 63C v001 0,144 против v002 0,000 (там, где общий балл #1724 не разделил: отрыв 0,427), 63B v005 0,075 /
v006 0,050 против v007 0,010, KPP1 w7 0,699.

**Что рекомендую.** Один метод для #1736 — **«решётка разрезов + поле глубины»** (split grammar для фасада):
1) контур = наружная оболочка (D341); 2) список линий **из архитектуры** (проёмы, зоны, пояса, этажи), а не из
вершин Revit, со снапом к модулю этажа; 3) линия держится, только если по ней меняется класс ячейки (стена /
проём / ниша / зона) на длине ≥ порога — иначе это текстура; 4) все грани строятся из ячеек решётки, вершины
общие — сварка, обход углов и квады получаются сами; 5) неповторяемые полосы (1-й этаж, верх, пояса) — свои
наборы уровней со **общими станциями** (как 63B v007), стык полос — по общей петле. Ремонт существующей сетки
запрещён: всегда пересборка с решётки. Прототип: 63A собран из формы v005 той же решёткой — 2,08 петли/этаж,
обход углов 1,0, повтор модуля 1,0, как у принятого; KPP1 W/S/N с 1-м этажом — 100 % квадов, 0 вееров, 0
диагоналей, локальный сигнал 0,007 (w7 — 0,699), **но линий больше эталона** (6,3 глобальных уровня на этаж
против 2–3): линии взяты из вершин R1, а не из списка проёмов — это и есть пункт 2, и для KPP1 нужен его
список проёмов/зон.

## 2. Анатомия эталонов: как идут петли (измерено)

горизонтальные рёбра на одной высоте покрывают ≥ 90 % периметра; **обход угла** — у вершины на ребре угла есть
горизонтали с обеих сторон; **повтор модуля** — сходство наборов станций на уровнях z и z + шаг; **T-трещина** —

Что видно и как это строится (рецепт, не проверка):

1. **Петли этажа — глобальные.** У всех принятых 2,1–3,2 глобальные петли на этаж (пол/подоконник, верх
   окна, у 63B ещё пояс), и они **обходят каждый угол** (1,000; у эталонов 0,998–1,000). Поэтому строится
   сначала набор уровней корпуса (на полосу этажей), потом стены — никогда наоборот. У KPP1 w7 глобальных
   петель 0 и обход угла 0,789: каждая плоскость резалась сама по себе (58 плоскостей на W).
2. **Вертикали — станции кольца.** Станция = излом контура, откос проёма, стык зоны отделки, деление
   длинной грани (BM-11). Станция проходит всю высоту модуля; повтор модуля 0,97–0,99 у решёток и 0,74–0,97 у
   эталонов НПМ (у эталонов есть доп. оболочки корзин). У 63B — 0,77–0,79: пояса и типовые этажи —
   разные кольца, станции общие (v007), но набор вершин на уровне пояса другой.
3. **Проём — вынутая ячейка + трубка откоса из 4 квадов на вершинах той же решётки.** Откос сварен со
   стеной по построению (0 несваренных пар у всех принятых). Отказ 63C v001: откос строился в системе окна
   и проецировался за поворот стены — 176 клиньев.
4. **Углы и скругления.** Угол — тоже станция; петли идут через него без разрыва. Скругление — станции по
   дуге ([D337]), петли этажа обходят дугу кольцом (63A: 4 угла R 1,4–1,8 м, обход 1,000).
5. **Где треугольники.** У ручных эталонов НПМ треугольники живут на **горизонтальных крышках** (G22 к.1 —
   6 654 треугольника крышек, веера в плане) и в 1-м этаже/верху; на типовом фасаде — единицы. У решёток
   этапа 1 их нет вообще. Крышка пояса/скругления строится лестницей квадов между станциями двух колец
   (63B v007, skill `belt-cap-quad-ladder`), а не триангуляцией плана.
6. **Мелкие оболочки отдельно.** У эталонов 301–1 470 оболочек (корзины, козырьки) — врезаны, стена под ними
   целая (BM-04). У решётки этапа 1 оболочка одна.
7. **Неповторяемая полоса (1-й этаж) — свой набор уровней на тех же станциях.** У KPP1 поставки заказчика
   глобальных петель 0,39 на этаж и частичных 19,3 — сеть ручная, с вееров и диагоналей (158 / 392), то есть
   это **не эталон чистоты**, а принятая поставка. Хороший эталон для 1-го этажа у нас есть только в G22
   (полоса «1-й этаж» в #1618: 5,5–29 % треугольников, плоские длинные треугольники у входов).

## 5. Что меняется в правилах BM и в #1736

Правила BM-01…14 остаются как **проверки**; добавляется **порядок построения**, и #1736 реализует только его:

1. **BM-00 (новое, главное). Тело строится только из решётки.** Вход: кольцо оболочки (BM-01/D341), список
   линий с причиной (проём, зона, пояс, излом, этаж) из Revit/DWG, полосы этажей. Выход: ячейки → квады,
   проём = вынутая ячейка + 4 квада откоса, ступени глубины — квадами между ячейками. Ремонт существующей сетки
   (R1, чужой мастер, прошлой версии) **запрещён**: правка = правка входа и пересборка.
2. **BM-02/03 переписать как правило входа:** уровень/станция попадает в решётку, только если по ней меняется
   класс ячейки на длине ≥ порога (предложение: 1,5 м или ширина проёма); снап уровней к модулю этажа
   (предложение 10 см); всё остальное — текстура [D344].
3. **BM-05/06:** убрать лазейку «диагональ допустима на неповторяемом 1-м этаже» для фасада (остаётся только
   для горизонтальных крышек в НПМ): 1-й этаж — своя полоса уровней на тех же станциях.
4. **BM-10:** полосы = типовой модуль + уникальные полосы (1-й этаж, пояса, верх), **станции общие** для всех
   полос (63B v007), стык — общая петля.
5. **Проверка (BM-14, #1739):** к листу добавить локальный сигнал по ячейкам (`loop_anatomy.py`:
   `cells_irregular_share`, худшая ячейка) — он разделил все пары, где общий балл #1724 не разделил.
6. **#1736:** ядро = обобщённый `module_build.py` (кольцо × полосы, откосы на тех же вершинах) + вход «список
   линий» + стыки полос; хуки задач только готовят вход (кольцо, линии, зоны). Новых сборщиков по кускам нет.

## 6. Вопросы Артёму (с рекомендацией)

1. **Тело — только из решётки, ремонт чужой сетки запрещён?** Рекомендую: да; правка — во входе (кольцо,
   линии), потом пересборка. Это BM-00 и основа #1736.
2. **Откуда линии 1-го этажа и неповторяемых полос?** Рекомендую: из списка проёмов/зон Revit или DWG
   (низ/верх проёмов, цоколь, пояс), снап 10 см; линии из вершин Revit не брать. Для KPP1 — снять список с R1 v003
   и показать тебе один лист 1-го этажа до сборки всего.
3. **Порог «линия с причиной»:** класс ячейки меняется на длине ≥ 1,5 м (или ≥ ширины проёма), короче —
   текстура. Рекомендую 1,5 м и проверить на KPP1 1-м этаже.
4. **Треугольники в теле:** на фасаде — 0 (и на 1-м этаже), в НПМ допускаются только на горизонтальных
   крышках. Рекомендую: да, BM-06(б) для фасада убрать.
5. **Лист для приёмки:** к wire добавить карту «локального сигнала» (ячейки с дефектом подсвечены). Рекомендую:
   да, в #1739.
