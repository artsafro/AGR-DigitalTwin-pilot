# Standing #76 — GroundEl 512 atlas source-scale preflight (OBSERVE)

## Frozen contract R1 (before rendering/scoring)

**Question.** Does a crop-size preflight flag the one rejected patterned cell of the D240 GroundEl atlas without flagging the five accepted patterned rows? This is a retrospective test of an already noticed ratio (#75), not independent calibration or a test of the cause of the rejection. The user accepted the r2 visual revision for new MAF only, not an automatic rule. The r2 crop also changed location, composition and cleanup. Not a regulatory texel-density or UV-padding check.

**Metric.** Signed source-pixel deficit `E76 = 1 - min(source_width / content_width, source_height / content_height)`. Use dimensions of the actual crop passed to the existing rasterizer, and the content rectangle (not the allocated slot). Candidate emits an observation only if E76 > 0; 1:1 is not flagged. Calibrate with `D76 = E76(r1 ID18) - max(E76 of accepted patterned rows)`; higher is better. No score for solids. Confirmation is fixture-local only: every round must have D76 >= 0.10, exactly the rejected real row flagged, zero accepted flags, zero changed pixels against published atlas outside the numbered corner in each patterned slot, all controls exercised and in bounds, paired spread <= 1e-12. All clean rounds with non-positive separation refute the ordering; otherwise incomplete/parity/budget/guard failures are inconclusive. No production keep under any outcome; an independent labelled pair is required before proposing a gate.

**Fixture and parity.** Use `library/maf/atlas_512_v007.json` at `88535418e4e259e29f1d2bff9d9dbf3a55bbb92f` (r1) and `01e48513aa9bba11553bc3c0c296414e7ba26c6d` (r2). Read source `53407` and delivered atlas PNGs at the exact Drive paths in these immutable manifests and verify all three file SHA-256 values before each round and afterwards. Each fresh process reopens the source PNG, executes `crop_slot` and `tools/materials/atlas_maf.py:render_atlas` at r2 revision for each patterned row, and compares the full slot including gutters except the declared number overlay rectangle to the published decode. The replay checks that both owner files, their two library imports, and `uv.lock` equal the pinned Git blobs (LF text normalization only); no font pixels enter the comparison. Labels: D240 / PR #1187, r1 ID18 rejected, all other patterned rows and r2 ID18 accepted. Source, both manifests, both atlas bytes and owner/lock revisions are required; Drive access limits replay. No sidecar crop is substituted for source readback.

**Controls (bound before measurement).** In-memory variants on clean ID18 crops, then fresh rasterization via the same owner; compare variant pixels to the simulated clean content and record changed pixel count, input dimensions and changed/unchanged support. Accepted r2 independently crosses the alert boundary: center trim to 247x247 -> +1/248; 248x248 -> 0; 249x249 -> -1/248. Rejected r1 positive trigger: center trim to 107x107 -> 13/120, still flagged. On both r1 and r2, RGB +8 with clipping must change rendered content and move E76 by exactly 0. Exact score bounds ±1e-12 and strictly positive decoded content changes for all six cases. All other rows untouched by variants, and all solids `not_exercised`, not measured as controls. An unexercised variant cannot count as invariance.

**Replay and budget.** `uv run --frozen python docs/research/maf-atlas-source-scale-r76/replay.py tmp/r76-NEW`. One pair times both real labels, collateral and controls; keep that pair, then repeat exactly twice in fresh processes with fresh PNG reads. Budget 1 calibration + 2 confirmation pairs, zero new candidates, hard stop 120 s for the measurement series or remaining card time if shorter. Each child gets the remaining series budget; after the first pair only continue if 2x its elapsed time fits. On a stop keep completed raw rows, report inconclusive for the run, and rerun the same command with a new directory and enough wall-clock time. Record median, three raw pairs, spread and elapsed separately. No pytest/delivery acceptance inferred from this replay.

**Do not touch:** released packages, sources, production atlas builders, geometry, UV, thresholds/checkers, test selection or other cards' files. No DCC needed for this PNG-crop stage. Skip AC08 pitch/width, padding and cross-profile drift already tested in #58–#74; KPP1 #1817/#1818, G22 #1649, MAF numbering #1809 and Staropetrovskiy #1500 are separately owned. No measurement on AC08, KPP1 v004, Vatutino or Staropetrovskiy in this round, and no transfer from this labelled atlas to those models. Closed form research remains closed.
