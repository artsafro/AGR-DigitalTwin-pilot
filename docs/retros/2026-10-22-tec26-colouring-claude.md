## 3. Как выглядел бы правильный прогон (входы утра 22.10)

1. **10:12–10:30, оркестратор сам.** Открывает сцену (опись ID), презентацию (распаковка pptx, слайды «Цветовое
   решение» по каждому корпусу + легенда 5015/7047/7004/9016), один DWG для сверки. Выписывает на здание таблицу
   «ID → материал → RAL → текстура → число рёбер по фасадам, со слайда N».
2. **10:30–10:40, одна форма вопросов ≤ 5**, с моим ответом первым: геометрию не трогаем? (да); швы и их число
   со слайда? (да); если не влезает — режем loop/ring? ; карты: UDIM 4K VPM, атлас 2048 NPM; приёмка = картинка
   «слайд | VPM | NPM» на каждый фасад. Режим light.
3. **10:40–11:30, один пилот (АС.08)** одним агентом со зрением: диффузы по таблице, UDIM, атлас, сравнение.

5. **11:30–12:30, веер.** АС.04–АС.07, АС.09 и труба параллельно тем же скриптом (рецепт зафиксирован коммитом

6. **12:30–13:00, приёмка пакетом**, один PR на job со скриптами в конце.
