- **Метод учёта:** площадь граней по материалу, который каждая грань показывает, до и после.

Стат. механизм перекраски (`:55027-55030`, `:55056-55067`): у первого объекта пары материал заворачивается в слот 1
Multi/Sub, а ID его граней остаются прежними. Бокс-примитив несёт ID 1…6. Объект без материала просто получает материал
соседа (`:55021-55024`).

## Вердикт лаборатории: `take_fix`
Брать идею корзин по материалу: Keep split даёт один объект на материал и сохраняет материалы точно. Это режим по
умолчанию для `model.attach_by_material` и шага Quick Attach.

Переписать:
- режим «один объект» — сначала собрать Multi/Sub, затем переназначить ID граней **каждого** источника через его
  таблицу «материал → слот»;
- геометрия без материала → явный слот `No_Material`;
- материалы — по экземпляру; одинаковые имена у разных материалов → предупреждение в отчёте;
- имена по К1 (`BODY_<material>_NNN`);
- дети: перепривязать или отказать с отчётом;
- одна запись Undo;
- бинарность не обязательна: последовательная склейка не медленнее на 2 000 объектов.

## Что меняется в требованиях issue
- Q16 («Quick Attach даёт один объект»): один объект допустим только с полной перенумерацией ID. В регресс — площадь
  граней по материалу до и после.
- В `source.intake` / `body.prepare`: проверка «материал каждой грани не изменился».

## Требования
К1 (имена `BODY_<material>_NNN`, роли), #1024 1.0.4 `body.prepare`.

## Минимальная приёмка
Синтетика как в `…efe08cb9`, сцены в м и в см:
1. **Материалы.** 200 боксов, три материала, Multi/Sub (2 слота, свои ID), Editable_Mesh, 5 без материала,
   2 разных материала с одним именем. Площадь граней каждого материала до и после совпадает с допуском 1e-6.
   Без материала → слот `No_Material`.
2. **Режимы.** «По материалу» → по объекту на материал. «Один объект» → Multi/Sub без потерь. Одинаковые имена — в отчёте.
3. **Иерархия.** Ребёнок и его родитель: ребёнок перепривязан к итогу или в отчёте `skipped` с причиной.
4. **Имена.** `BODY_<material>_NNN`.
5. **Undo.** Одна запись; один undo возвращает все исходные объекты.
6. **Время.** 2 000 боксов ≤ 10 с.
7. **Отчёт.** Объекты в / объекты из, материалы, предупреждения; пустой вход — ошибка.
