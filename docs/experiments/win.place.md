## Вердикт лаборатории: `take_fix`
Кадр `:56942-57025` для плоских прямоугольных проёмов с откосами точен — это база модуля `openings`. Переписать:
- отсеивать внешние контуры;
- классифицировать петлю: прямоугольник / не прямоугольник (доля площади петли в габарите) / две плоскости. Иначе — `ambiguous`;
- угловой проём: две ветви по плоскостям стен или `ambiguous`;
- нормаль — явно к улице от откоса; ось лица окна — из записи библиотеки, без авто-поворота;
- выравнивание по центру; порог в метрах (`units.SystemScale`) по каждой оси;
- не трогать пивот источника; отчёт `done`/`skipped`/`ambiguous`, черновик типа для непоставленных (К2);
- Snap — только отдельной опцией, кластер в метрах, без разрушения инстансов.

## Минимальная приёмка
Синтетика `gen_badik.py` (GeoAGR-private, `work/lab-experiments/_lib-v10-L10/`), сцены в м и в см:
1. **Точность.** 12 проёмов KPP1-W01..W03 на стенах 0°, 90°, 30° и у края стены. Ошибка центра ≤ 5 мм, нормали ≤ 0,5°,
   верный тип, лицо окна к улице для моделей с любой осью лица из записи библиотеки.
2. **Отсев.** Внешние контуры фасада не дают ни кадра, ни окна.
3. **Неоднозначность.** Нестандартный 1,5×1,5, арка и 2 угловых проёма → `ambiguous` в отчёте плюс черновик. Ни одного
   прямоугольного окна в арке.
4. **Порог.** Апертура W01 +10 мм → принята, центр совпадает; +50 мм → `ambiguous` (при пороге 20 мм). Одинаково в м и в см.
5. **Источник не меняется.** Пивот, трансформ и инстансы исходных окон до и после совпадают.
6. **Undo.** Одна запись; один undo возвращает сцену; выделение восстановлено.
7. **Отчёт.** Поставленные / пропущенные / `ambiguous` с причинами; пустой вход — ошибка.
