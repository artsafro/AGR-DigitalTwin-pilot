# Hypothesis #359 — farthest-anchor projection

**Verdict: REJECTED as specified. `delivery_passed=false`.**

The speed thresholds pass, and A/B full-result parity is exact. The mandatory
inherited-original crossing labels do **not** survive every prescribed edge
subdivision: 48/6400 derivative variants fail per repetition under **both** A and B.
This rejects the complete claim, not the observed selector equivalence. No adoption,
production fix, tolerance change, alternative population, or retuning was attempted.

## Semantic rejection and exact counterexample

[semantics.json](../../experiments/hyp-359/semantics.json) records three complete
runs, full-result hashes and the first failures. Each run covers **16,328 cases**:
9,920 originals, 6,400 derivatives, eight timed long cases. All six A/B full-result
streams hash to:

`6a5e1915f383ecd9b4127f75c40a71bca6a7f08301a9471955e3a35012a906a5`

The original exact oracle functions were reused, not production projection code.
The mandatory derivative labels were inherited exactly as instructed; each
expanded geometry was compared against its own baseline, not its original's
other counters. No input mutation, exceptions, missing cases, A/B dictionary
differences or report-only flag changes occurred.

**First counterexample:** original index **133**,
`[(13,2),(9,-3),(-1,1),(13,8),(-13,1)]`, factor **2**, XY, forward, shift 0.
Original oracle pair count is **1**, so required inherited flag is **1**; A and B
both return **0**. Their entire dictionaries agree (10 vertices, 10 boundary
edges, eight triangles, one component, both certification flags false).

The post-measurement [diagnose.py](../../experiments/hyp-359/diagnose.py) and
[diagnosis.json](../../experiments/hyp-359/diagnosis.json) retain all **48** failing
variant keys/full dictionaries and independently explain the cause with exact
`Fraction` determinants. Original edges **2** and **4** intersect at `(0,3/2)`,
with parameters **1/14** and **1/2**. Splitting edge 4 in half turns that crossing
into an endpoint contact, which unchanged **strict proper-crossing** tests exclude.
The same inherited-label issue affects polygon 133 at factors 2 and 4 and polygon
79 at factor 4: 3 expanded outlines × 16 variants = **48 failures per run**,
**144/48,984** across three repetitions.

This diagnoses a false subdivision-invariance premise in the requested conjunction,
not a selector regression. The original oracle/generator construction is correct,
and the prescribed inherited-label rule was executed verbatim on valid frozen
cases; this is an executed acceptance violation, hence **REJECTED**, rather than
silently replacing labels or weakening the requirement. Exact derivative labels
were used **only** for diagnosis after measurements, never to rescue acceptance.
A differently scoped selector-adoption experiment would require separate approval.
