- How the comparison works:
  - Each output vertex is keyed by its sorted complete vertex-source group.
  - Each output face is keyed by (sorted face-source group, arity, its cycle of vertex keys rotated to the
    minimum start). Reversed winding is NOT treated as equal.
  - These keys are compared as multisets against the identity case. Dropped-vertex records are compared as a multiset.
  - Vertex deviation: Euclidean distance after the inverse transform, per matched vertex-source group.
