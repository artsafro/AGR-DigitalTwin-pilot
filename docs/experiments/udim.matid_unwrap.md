## Что измерено (изм.)
МАФ: 5 боксов разного размера в одном Editable_Poly, MatID 1, 2, 7, 12, 40.

| MatID | 1 | 2 | 7 | 12 | 40 |
|---|---|---|---|---|---|
| UDIM | 1001 | 1002 | 1007 | 1012 | 1040 |

- Правило: `UDIM = 1001 + (ID−1) mod 10 + 10·⌊(ID−1)/10⌋` (= `1000 + ID` при ID ≤ 10) — совпадает с `udim.ids_to_udims`.
  Разреженные ID оставляют пустые тайлы.
- Каждый ID нормализуется в свой тайл с полем 0,02 UV (`spacing` — в UV). Перекрытий нет.
- Плотность на карте 1024: 317…635 px/m, среднее 427 — **одинаково в метрах и сантиметрах**; разброс ×2 между ID из-за
  нормализации.
- Исходная UV базового объекта не трогается; результат — в `Unwrap_UVW` поверх стека. EPoly + Bend: Unwrap над Bend, Bend цел.
  **Примитив + Bend: конвертирован в Editable_Poly, Bend схлопнут молча.**
- MatID сохраняются; висячих map-вершин 0; одна запись undo.
- Панель Modify нужна, функция переключает её сама; в batch работает.
- Время: 2048 полигонов — 0,74 с; 5000 — 1,07 с.
- Упаковщик (`gap` 0,005 — в UV): на объекте с Unwrap_UVW — «тайлы не найдены», UV не изменена; после схлопывания стека —
  острова уложены столбцом шириной 1 UDIM, два из пяти пересекают границы UDIM (1021/1031, 1031/1041), порядок ID не сохранён.

## Дефекты источника
1. Схлопывание пользовательского стека у не-Editable_Poly объектов без предупреждения (`:192`).
2. Разная плотность между ID (нормализация каждого ID).
3. Упаковщик не читает UV через Unwrap_UVW, оставленный первым шагом.
4. Упаковщик кладёт острова через границы UDIM и теряет соответствие ID → тайл.
5. Побочный эффект: панель Modify и текущий модификатор.
Замечание плана «единица TD не подписана» не подтверждено: в UI подпись `px/m`, пересчёт через SystemScale верный (стат. + изм.).

## Рекомендация: `take_fix`
Правило ID → тайл брать как есть (общее с `udim.ids_to_udims`). Работать на копиях экспорта, не схлопывать пользовательский
стек, опционально выравнивать плотность px/m между ID (`units.SystemScale`), упаковщик — по UV вычисленного меша, острова в
пределах одного UDIM.

## Минимальная приёмка
Синтетический МАФ (MatID 1, 2, 7, 12, 40) в метрах и в сантиметрах, плюс копия с Bend на примитиве:
- каждый ID ровно в своём тайле (1001, 1002, 1007, 1012, 1040), перекрытий UV нет, все острова внутри своего UDIM;
- плотность px/m на карте 1024 совпадает в м и см (±1 %); при включённом выравнивании разброс между ID ≤ 5 %;
- оригинал не изменён (классы, стек модификаторов, UV, MatID — хэши до/после), результат только на копии;
- висячих map-вершин 0; 5000 полигонов — < 5 с;
- упаковка атласа: острова не пересекают границы UDIM, зазор ≥ заданного в UV.
