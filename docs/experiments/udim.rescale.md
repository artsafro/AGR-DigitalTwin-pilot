1. Плотность в системных единицах (см-сцена ×100). 2. Масштаб вокруг центра выделения — остров уходит из тайла,

5. Молчаливые отказы (Create, пустое выделение).

## Вывод и формула
Подтверждено «системные единицы и перезапись карт». Для ядра: `sc = target_px_m / (S · sqrt(A_uv / A_m²))`,
`A_m² = A_units² · SystemScale²` (м через `units.SystemScale`, без `decodeValue`); масштаб вокруг **общего нуля
проекции** из паспорта и **до** укладки К6; без `breakSelected`; карты не переписывать (тексель задаёт UV).
Рекомендация: **take_fix**.
