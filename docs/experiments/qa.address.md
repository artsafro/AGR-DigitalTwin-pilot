## Дефекты источника
1. Токены 2–3 обязаны быть улицей: `Str`, `K`, `D`, `Dom`, `Zu` рядом с номером дома → ложная ошибка (`GeoAGR.ms:15513`).
2. Пустые токены теряются: лишние `_` не видны.
3. Нет проверки длины.
4. Сравнение по подстроке: улицы с `Park`/`Val`/`Sad` → ложные ошибки.
5. Конфликт с правилом числительного (`2j…`).
6. Мутация токенов между правилами (`GeoAGR.ms:15466`) → каскад ложных сообщений; регистр сообщается как «нет в классификаторе».
7. Ошибки чтения CSV не обрабатываются (склейка текстов, исключение).
8. Результат — только окно с формулировками «возможно…».
