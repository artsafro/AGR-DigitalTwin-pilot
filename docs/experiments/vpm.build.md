## Правило для ядра (К6), вывод
- UV из **локальных** координат объекта (× `units.SystemScale` → м) + смещение пивота от общего нуля паспорта в double;
  `u = (s0 + (p−A)·t)/P`, `v = (z − z0)/P`, P — целое число раппортов на UDIM.
- `s0` — длина цепочки стен материала (развёртка по периметру): углы непрерывны; проекция «по осям» рвёт углы.
- Резка граней по целым линиям UV плоскостями (идея UDIM Slicer без притяжки), затем каждой грани целый сдвиг
  `T − floor(центроид)` в тайл материала (перенумерация К3). Масштаб при укладке не меняется.
- **Противоречие К3 ↔ К6 (вопрос):** 1024 px/м на 4K = 4 м на UDIM — это не целое число панелей 1,2/0,6 м и кирпичей
  0,26/0,15 м; бесшовная плитка требует 3,6 м (1137,8 px/м) / 3,9 м (1050,3 px/м) или модуль, кратный 4 м.

Рекомендация: **new** (GeoAGR Unwrap Tiles / UVs Grouper не брать; брать идею резки по сетке UV).
