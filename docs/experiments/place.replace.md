## Формула верного oriented bbox (изм. на 7 дверях, вершины двери внутри бокса с допуском ≤ 3e-5)
Для двери берётся `ot = objectTransform`:
- `e1 = normalize(ot.row1)`, `e2 = normalize(ot.row2 − (ot.row2·e1)·e1)`, `e3 = e1 × e2`;
- для каждой мировой вершины `p`: `q = ((p − ot.row4)·e1, (p − ot.row4)·e2, (p − ot.row4)·e3)`, `lo`/`hi` — минимум и максимум `q`;
- бокс: ширина `hi.x − lo.x` по X, длина `hi.y − lo.y` по Y, высота `hi.z − lo.z`;
- пивот Box в центре основания, поэтому трансформ = `(e1, e2, e3, ot.row4 + e1·(lo.x+hi.x)/2 + e2·(lo.y+hi.y)/2 + e3·lo.z)`.

Вершины берутся в мировых координатах один раз. Масштаб ноды входит в `q` сам, повторно на `objectTransform` не умножать.
Проверено: identity, пивот в основании, поворот 30° со смещённым пивотом, ребёнок повёрнутого родителя, Editable_Mesh,
наклон 10°, масштаб [1,2,1].
