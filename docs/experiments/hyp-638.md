## Verdict

**REJECTED.** The real-arm threshold is 0 changed tuples, and the measured value is 43/386 in both VPM and NPM. The synthetic family passes: 0 label errors in 768 variants,
0 changed non-crossing controls, 0 exceptions, 0 mutations, identical repeats. That does not offset the real failure. Per the issue, this result
documents a counterexample. It does not authorize tuning an epsilon or snapping to the boundary. A veto that ignores endpoint touches
within some tolerance would be a new hypothesis, with its own frozen threshold. No adoption scope.
