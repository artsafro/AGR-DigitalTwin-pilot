## Отличие от Light_Metr (по T04/T05)
Light_Metr переводит пороги через `units.decodeValue` (на ru-RU 1.5m → 1.0), GeoAGR не переводит вовсе. Пороги и строгое
«меньше» совпадают.

## Дефекты источника
1. Пороги в системных единицах — пропуски в см-сцене. 2. Недопустимый тип в списке: его пары не проверяются и итог «OK» не
выдаётся. 3. Список обрезается до 250 без сообщения — остальные не проверяются. 4. Количество и расстояния считают разные множества
(Photometric/Skylight). 5. Результат — окно + выделение, без отчёта.

## Рекомендация: `merge` (как в плане)
Слить с исправленным Light_Metr: метры через `units.SystemScale` (никаких строк), строгое «<», 3D по позиции источника, все пары
Omni/Spot без лимита 250, недопустимые типы — отдельный список, но их наличие не отменяет проверку пар; один отчёт (пары, d в м,
классы) + выделение нарушителей.
