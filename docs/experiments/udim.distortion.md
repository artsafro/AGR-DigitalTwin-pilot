## Дефекты
1. Нормировка Area на среднее по объекту. 2. Angle по первым трём вершинам. 3. Edge зависит от текселя и единиц.
4. Путь Unwrap молча показывает «без искажений». 5. Примитив — исключение. 6. Нет порога и машинного отчёта.

## Вывод и метрика для AGR
На каждый треугольник — якобиан UV → м, сингулярные числа σ1 ≥ σ2: масштаб `sqrt(σ1·σ2)·S` против целевого текселя
(px/м через `units.SystemScale`), порог ±1 % (как приёмка `vpm.build`); анизотропия `σ1/σ2`, порог 1,02 (≈ 1° скоса);
зеркальность по знаку детерминанта. Любой класс объекта (вычисленный меш), машинный отчёт, без смены выделения,
материалов и вершинного цвета. Рекомендация: **take_fix**.
