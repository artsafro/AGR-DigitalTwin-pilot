## Вердикт лаборатории: `new`
Генератор строит раму по `panes_m` с элементами стандарта. Профиль, глубина, импост и положение стекла — параметры
из `standard.json`; по умолчанию F100, для роли «дверь» — F73. Слияние типов — только по совпадению разбивки, не по
габариту.
