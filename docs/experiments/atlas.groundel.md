## Правило (изм., вызов функции правила)
| Файл | 512 (GroundEl) | 2048 |
|---|---|---|
| 128², 256², 512² PNG; 512² JPG; 512² gray 8 бит | OK | OK |
| 1024², 2048² | ошибка размера | OK |
| 513², 384², 64² | ошибка размера | ошибка размера |
| 512×256, 256×512 | не квадрат + ошибка размера | то же |
| 512² RGBA (alpha 0,5 или полностью непрозрачная) | ошибка «есть альфа-канал» | то же |
| 512² 16 бит | предупреждение о глубине | то же |
| отсутствующий файл | **ничего** | ничего |

Точное правило лимита 512: допустимы только квадраты 128, 256, 512 px; больше 512, не степень двойки, меньше 128, не квадрат —
ошибка; любой альфа-канал в файле — ошибка; глубина ≠ 8 бит — предупреждение; формат (PNG/JPG) не проверяется. Сообщения
пишутся в список окна Errors, без всплывающих окон.

## Кнопка «Find errors» (изм.)
Проверки OKS и Ground выполняются, затем обработчик падает: обращение к контролу GroundEl, которого нет в rollout
(`:1374` против объявления `:557`), — исключение MAXScript. **Лимит 512 для GroundEl через кнопку не выполняется никогда**
(карта 1024 для GroundEl не найдена); Flora, сравнение размеров и проверка единиц тоже пропускаются. Пустые карты OKS/Ground не
сообщаются (подпись кнопки по умолчанию не пустая).

## Блокирует ли экспорт (стат.)
Нет: список ошибок читается только окном Errors; функции экспорта (`:1244`, `:1253`, `:1270`, `:1285`) его не используют.

## Дефекты источника
1. «Find errors» падает до проверки GroundEl — правило 512 мёртвое в живом UI.
2. Отсутствующий файл карты пропускается молча; пустые карты OKS/Ground не сообщаются.
3. Любой альфа-канал (даже непрозрачный) — ошибка.
4. Проверка не блокирует экспорт.

## Рекомендация: `merge` (как в плане)
Режим `groundel` в `atlas.npm`: квадрат, степень двойки 128…512 (больше 512 — ошибка), отсутствующие/неуказанные карты — явная
ошибка, альфа — по фактическим пикселям или по роли карты, 8 бит; результат структурный и может блокировать экспорт.

## Требования строки
`NPM-2.5-12`, `NPM-2.1-5.b`. Режим `copy`.

## Минимальная приёмка
Набор GroundEl-карт, сделанный тестом: 128², 256², 512², 513², 1024², 512×256, 512² PNG с альфой 0,5, 512² PNG с непрозрачной
альфой, 512² JPG, 512² 16 бит, отсутствующий файл, не указанная карта:
- 128², 256², 512² PNG/JPG → OK; 513², 1024², 512×256 → ошибка с размером; отсутствующий и не указанный → ошибка «нет карты»;
- альфа 0,5 → ошибка (или по роли карты — по требованию НПМ), непрозрачная альфа — по выбранному правилу, но одинаково в тесте и
  в Max; 16 бит → предупреждение;
- проверка Ground/OKS (2048) и GroundEl (512) в одном прогоне, без исключений, отчёт JSON; при ошибке GroundEl экспорт режима
  `groundel` не выполняется.
