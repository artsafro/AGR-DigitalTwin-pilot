# qa.omk_te — код ОМК ТЭ: что делает GeoAGR Get OMK TE Code (L15, #1024)

Лаборатория AGR Tools 1.0, лот L15, ПК No_Defender, 3ds Max 2026. Источник — Get OMK TE Code
`GeoAGR.ms:66030-66187`, диалог `TableOMKTE` `:66047-66185`. Синтетическая таблица 50 строк своего формата;
справочник GeoAGR читался только в изолированной папке джоба — в отчёт и пилот попали только агрегаты (вопрос 18:
CSV GeoAGR не копируется). Доказательства — GeoAGR-private, ветка `lab-exp/10-L15`, `work/lab-experiments/qa.omk_te/`.
Метки: **изм.** (job id), **стат.**, **гип.**

## Что измерено
Джобы `20261106-015253-omk_main` (синтетика), `20261106-015411-omk_ref` (справочник). Диалог dotNet в batch
строится; кнопки нажимались программно.
- **изм. Дефект Copy при фильтре подтверждён.** При активном фильтре Copy кладёт в буфер N-ю строку **всей
  отсортированной таблицы**, а не N-ю видимую; Paste (поле в панели) — правильную видимую: синтетика 3 из 3,
  справочник 6 из 6 (5 580 строк). Без фильтра Copy = Paste.
- **изм.** Фильтр регистронезависим и ищет и по месту, и по коду (статическое «регистрозависим» не подтвердилось).
- **изм.** Код короче 4 знаков дополняется нулём (`905` → `0905`).
- **изм.** Ячейка с несколькими кодами: предупреждение «выберите один код», но в буфер и поле уходят оба.
- **изм.** Пустая строка или строка без кода ломает сортировку (26 пар не по порядку).
- **изм.** Нет CSV — пустой диалог без сообщения; CSV занят — сообщение в неверной кодировке.
- **изм.** UTF-8, UTF-8 BOM, UTF-16 читаются без искажений; CP1251 — **не измерено** (ошибка харнесса).
- **изм.** Ctrl при открытии — вторая таблица (TE2); сцена не меняется; остаются глобалы `arr_excel`, `filt`,
  `dirs_select`, `TableOMKTE`.
- **изм.** Справочник (агрегаты): TE3 — 5 580 строк, 3 156 кодов короче 4 знаков, 526 ячеек с несколькими кодами,
  5 195 повторов кода; TE2 — 809 строк.

## Что известно статически
- **стат.** Путь жёсткий: `<Max root>\GeoScripts\OMK_TE3.csv` (Ctrl — `OMK_TE2.csv`) `:66033-66034`; табуляция,
  колонка 2 — место, 3 — код `:66042`.
- **стат.** Причина дефекта: Copy берёт строку по индексу видимого списка из полного массива `:66134`; Paste —
  из отфильтрованного `:66147-66158`.
- **стат.** Результат уходит в поле панели и дальше в имена экспорта `:66541`, `:66622`, `:66640`.

## Вердикт: `new`
Своя реализация: путь к таблице — параметр, своей таблицы в пакете нет (вопрос 18). Режим `read`; код пишется в
паспорт и пакет (этап 9).

## Формат таблицы-параметра (предложение)
UTF-8, табуляция, заголовок `place<TAB>code`; код — строка из 4 цифр (ведущие нули сохраняются); одна ячейка — один
код. Валидатор отчитывается: короткие коды, несколько кодов в ячейке, повторы, пустые строки — `ambiguous`, не
молча.

## Минимальная приёмка
1. Таблица 50 строк (синтетика), фильтр → 4 видимых строки, выбор 2-й: в паспорт/буфер уходит код 2-й **видимой**
   строки (регресс на дефект `:66134`, RED на поведении GeoAGR → GREEN).
2. Фильтр регистронезависим и по месту, и по коду.
3. Код `905` хранится как `0905`; ячейка `9047 9048` → `ambiguous`, ничего не записано без выбора.
4. Пустая строка и строка без кода не ломают сортировку, попадают в отчёт.
5. Нет файла / файл занят / не UTF-8 → понятная ошибка в отчёте (по-русски, без кракозябр), сцена и паспорт не
   меняются.
6. Путь — параметр; в пакете AGR Tools нет копии справочника GeoAGR.
7. Кнопка не меняет сцену (хэши), не оставляет глобалов.
