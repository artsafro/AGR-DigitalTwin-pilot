## Круговой путь ВПМ → НПМ → ВПМ (изм., `…005641-roundtrip`)
| Путь | UV и UDIM | Тексель | Материалы |
|---|---|---|---|
| прототип `npm.build` → обратно по таблице | UV = ВПМ до 3·10⁻⁶; 512/512 треугольников в исходном UDIM | 1024 px/м | исходные библиотечные, слот = ID |
| прототип → без таблицы (регион на ID) | ID → UDIM 1000+ID; ошибка кропа ≤ 0,02 px (A, B) | 39 px/м (вырезки атласа) | новые, по ID |

## Окна-плейны (изм., прототип AGR)
14 плейнов: 4 × KPP1-W01, 4 × KPP1-W02, 4 × KPP1-W03 на 5 стенах (одна под 17°, часть плейнов из 4–6 граней) + KPP1-W03,
повёрнутый на 90° в своей плоскости, + 1,5 × 1,5 м без типа; шум размеров до 4 мм.

| Метод | Метры | Сантиметры |
|---|---|---|
| прототип: элементы ID окна → кадр (нормаль по площади, верх = мировой Z) → ширина/высота → тип по размеру, порог 0,05 м, вариант 90° → инстанс | **14/14**, центр 0 мм, нормаль 0°, отклонение от типа ≤ 7,5 мм; 13 инстансов, плейны в скрытом слое `_npm_src` | 14/14 |
| принцип GeoAGR: без 90°, порог 0,2 в системных единицах | 13/14 (повёрнутое не найдено) | **1/14** (0,2 см < шума 4 мм) |

Ошибки центра и нормали 0 — свойство точной синтетики (прямоугольные плейны); на реальной НПМ их задаст шум геометрии (гип.).

## Вердикт лаборатории: `new`
- Из UnAtlas не брать ничего, кроме идеи слияния пересекающихся островов в стопку (для режима без таблицы).
- **Главный путь — по таблице соответствия из паспорта** (изм.: точный возврат UV, UDIM, текселя и библиотечных
  материалов).
- **Без таблицы** — регион на ID, кроп и UV по одной формуле в целых пикселях, родной размер вырезки, слот = ID,
  UDIM = 1000+ID (изм. ≤ 0,02 px).
- **Окна** — по прототипу: порог в метрах, вариант 90°, отказ «нет типа», инстанс сгенерированного окна, плейн в скрытый слой.

## Что меняется в требованиях issue (1.0.24)
- Таблица соответствия в паспорте — **обязательна** для приёмки «материалы и UDIM совпадают с исходным ВПМ»: без неё
  библиотечные материалы и тексель 1024 px/м не восстановить (без таблицы — только вырезки атласа, 39 px/м).
  Поля: ID, исходный UDIM (из паспорта, не из UV), ключ/ID материала библиотеки, карта, масштаб, сдвиг (u, v), ячейка в px,
  размер атласа, тексель цели.
- Режим без таблицы: ID не перенумеровывать, UDIM = 1000+ID, вырезки не растягивать до 2048.
- Окна: порог задаётся в метрах; вариант 90°; для библиотек с близкими размерами — отказ по неоднозначности (гип.).
- Вход UnAtlas-режима: принимать и Shell-материал (брать baked), иначе явный отказ.

## Минимальная приёмка
Синтетика лота и KPP1 НПМ из 1.0.22, Max 2024 и 2026, метры и сантиметры:
1. **По таблице.** UV возвращённой ВПМ = UV исходной ВПМ ± 1·10⁻⁵; каждый треугольник в исходном UDIM; слоты и
   материалы = библиотечные из таблицы; тексель 1024 px/м ± 1 %.
2. **Без таблицы.** На атласе с 16-битной координатой: ID 2, 5, 9, 12 остаются на гранях, UDIM = 1000+ID, ошибка кропа
   против UV ≤ 1 px (в т. ч. стопка у края атласа); размер вырезки = размер региона.
3. **Стопка вне первого UDIM** — обработана или явный отказ в отчёте, не только Listener.
4. **Окна.** 12 плейнов KPP1-W01..03 + повёрнутый на 90° + без типа, шум 4 мм: распознано 100 % (повёрнутый — с поворотом,
   без типа — «нет»), центр ± 5 мм, нормаль ≤ 0,5°; одинаково в м и см; плейны в скрытом слое `_npm_src`, инстансы по типам.
5. **Исходники.** НПМ-объект и его карты не меняются; существующие файлы не перезаписываются.
