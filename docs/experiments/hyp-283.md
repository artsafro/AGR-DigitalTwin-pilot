# Hypothesis 283 — first-occurrence group index

**Verdict: SUPPORTED on the frozen synthetic inputs; `delivery_passed=false`.**
This is an offline experiment, not a production optimization or delivery approval.
Full-suite validation is incomplete (400-second timeout). The smallest interleaved case
is only 0.0505 percentage points inside the permitted slowdown; do not generalize it.

## Scope and implementation

Base revision: `8e539b9a2a020fcf045eb9445e5940a3d87977c7`.
Source: [`check_complexity`](../../src/twinqa/geometry/complexity.py).
Area context: [GroundEl/MAF](../domain/areas/groundel-maf.md); these synthetic scenes
are checker-performance inputs, not architectural models, MAF etalons or regulatory evidence.

[`driver.py`](../../experiments/hyp-283/driver.py) reads the unchanged function with
`inspect.getsource`, asserts exactly two original first-object searches, and compiles
an experimental copy in memory. The sole algorithm change is a local `first_group`
dictionary, populated once after the ordinary triangle-budget pass with `setdefault`.
Only the two `next(...)` expressions become `first_group.get(name)`. The index is
rebuilt every call; it retains the first group even if that group is `None`.
No geometry hashing, budgets, metadata rules, ordering, truncation or reporting policy
is changed. No production, data, benchmark, dependency, CI, hook or wrapper files changed.

## Frozen inputs and protocol

The driver is the deterministic fixture specification; SHA-256 manifests are in
[`results.json`](../../experiments/hyp-283/results.json). Each scene is constructed
before warm-up/timing, frozen as complete serialized bytes, and checked against those
bytes after each call. Digests identify inputs; **digest equality is not the parity oracle**.
Output and exception parity uses full serialized bytes, including dictionary/list order,
exception module/type/args/message, and snapshots of both scene and tolerance inputs.
Serialization preserves NaN/Infinity tokens for the semantic probes (Python JSON dialect).

- Six performance scenes: exactly 10,000 objects; K=32/256/1024 meshes. Mesh `i` is a
  triangle with width `1+i/100`, material `i`, and four-point section metadata. Every
  object is in `piers`. All real geometry hashes are computed; no fake/cache hash.
- Interleaved order: `i % K`. Grouped order: stable numeric sort of these mesh IDs.
  Names, geometry, metadata and budgets are deterministic; object copies share types.
- Budgets: piers/walls/storey_bands=100,000 each; total=100,000; decor groups piers
  and storey_bands; section maximum=12; minimum silhouette deviation=0.07 m.
- One untimed warm-up per variant/scene, then seven pairs, alternating AB/BA starting
  AB. `perf_counter_ns` surrounds the **whole function call**, including all hashing,
  type/element aggregation and result creation. Fixture generation, byte comparisons,
  and separate parity calls are outside timing. Each timed output is compared too.
- Gain = `1 - median(B seconds) / median(A seconds)`, not median individual ratios.
- Independent confirmation: fresh process and fresh fixtures, three AB/BA/AB pairs
  for each K=1024 layout. No sample trimming, best-of selection or threshold tuning.
- Initial run's within-process confirmation is preserved in
  [`initial-results.json`](../../experiments/hyp-283/initial-results.json); the final
  verdict uses the subsequent separate-process confirmation in `results.json`.
  The first separate-process confirmation ran concurrently with the required full-suite
  attempt; it is preserved in `loaded-confirmation-results.json`. Two subsequent
  separate-process confirmations followed evidence-gate and process-provenance fixes;
  the intermediate one is in `confirmation-774384.json`, the last in `results.json`.
  All three independently exceeded 20% in both layouts (91.9974/58.2178%,
  91.0960/65.7331%, 91.8136/46.6839%). No primary sample was rerun or replaced.
  Final confirmation was after the full-suite timeout, without a concurrently launched
  suite. Other machine load was not controlled. Timings were not selected by gain.
  The recorded primary PID was not captured; predecessor PID metadata was corrected
  without changing timings. The final evidence gate requires independent confirmation;
  earlier artifacts' verdict fields predate this hardening and are not final approval.

### Frozen semantic matrix: 141/141 exact matches

128 cases are the Cartesian product of two first/second memberships in
`{piers, walls, storey_bands, None}` and eight metadata pairs:
`(4,None), (12,.07), (13,.08), (8,None), (None,None), (8,NaN), (8,+inf), (NaN,.08)`.
Both objects reference m0 with conflicting memberships; m1 remains unused. This covers
first-occurrence precedence, absent references, frame exemption, section-point limits,
missing metrics, non-finite metrics, silhouette boundary and decor/non-decor handling.

The remaining 13 cover absent meshes/objects fields; empty unsupported scene; empty
mesh/object inventories; absent mesh/group fields; unknown and unhashable references;
duplicate geometry; polygon hashing; malformed vertices; absent metadata; exact budget
and total equality. Results: **133 complete outputs + 8 complete exceptions**, exact A/B
parity, no mutation. All outcomes and input digests are retained, not just pass/fail flags.

**Policy conflict:** unchanged production accepts some empty/non-finite inputs and exact
budget equality. Changing those results would violate this issue's explicit exact-parity
and no-policy-change constraints. They are recorded, not silently repaired or treated as
delivery approval. Fail-closed rules below govern the *experiment evidence verdict*;
they do not assert that the production validator is fail-closed on those inputs.
