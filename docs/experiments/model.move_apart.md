## Вердикт лаборатории: `new`
Ни одна из трёх кнопок не даёт таблицы «зазор × диапазон → сдвиг», пригодной для ядра.

Своя реализация:
- поиск пар граней: параллельны в пределах угла, перекрываются в проекции, зазор в [min, max] в метрах
  (`units.SystemScale`);
- пара спиной к спине: каждая грань по своей нормали;
- сонаправленная пара: одна сторона по общей нормали;
- целевой зазор = To (записать явно);
- отчёт: найдено / сдвинуто / пропущено;
- без глобалов; одна запись Undo.
