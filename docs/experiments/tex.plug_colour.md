## Итог (изм.)
| Текстура | Строка списка GeoAGR | Записано |
|---|---|---|
| однотонная (200 100 50) | «200 100 50 = 99%» | **(149 32 7)** — темнее |
| однотонная серая 128 | «= 99%» | **(55 55 55)** |
| 9,4 % синего первыми в обходе, 90,6 % основного | «0 0 255 = 10%; 200 100 50 = 90%» | **синий** — первый найденный, не частый |
| синий только в строке 0 | «200 100 50 = 99%» | строка 0 не читается |
| RGBA: половина прозрачного красного | «255 0 0 = 50%; 0 255 0 = 50%» | **непрозрачный красный** |
| RGBA: 62,5 % прозрачного чёрного первым | «0 0 0 = 61%; …» | **непрозрачный чёрный** |
| палитровый PNG 30/70 | доли верные | цвет 30 % (первый), RGB вместо палитры |
| 512², 256×1024 | цвета не считаются | не тронуты, модальное окно на каждый |
| JPG | нет в списке (только `*.png`) | не тронут |

- **«Популярный» = первый найденный** — гипотеза плана подтверждена.
- **Строка 0 не читается:** обход строк с 1 при нумерации с 0. Проценты занижены (99 % вместо 100 %).
- **Альфа не учитывается.** RGBA и палитра становятся RGB 8 бит.
- **Цвет темнеет на гамму ≈ 2,2.** В слоте Max `fileInGamma` = `fileOutGamma` = 2,2. Стат.: результат зависит от
  настроек гаммы Max.
- **Перезапись исходников на месте без копии:** 7 из 7 PNG.
- **Время:** 0,5 с на 9 файлов.

## Вердикт лаборатории: `new`
Своя реализация:
- гистограмма по всем пикселям с весом альфы (α = 0 не считается);
- мода; при равенстве — в отчёт;
- поля отчёта: файл, размер, число цветов, топ-N с долями, доля прозрачного, выбранный цвет, решение;
- новый файл-заглушка (режим `copy`), исходник не трогать;
- PNG / JPG / TGA; большие текстуры — выборкой, а не пропуском;
- значения цвета сверять после записи (гамма 1,0).

## Минимальная приёмка
Синтетика как в `…7907def9`:
1. **Цвет.** Однотонная 64² (200 100 50) → заглушка (200 100 50) ± 0. Серый 128 → 128.
2. **Мода.** 9,4 % синего первыми + 90,6 % основного → основной. Цвет только в строке 0 учитывается.
3. **Альфа.** 62,5 % прозрачного чёрного + 37,5 % зелёного → зелёный; доля прозрачного в отчёте.
4. **Форматы.** PNG (RGB, RGBA, палитра), JPG, TGA читаются. 512² и 256×1024 → результат без модальных окон.
5. **Исходники.** SHA256 всех исходных файлов до и после совпадают; заглушка — новый файл.
6. **Отчёт.** Поля из раздела «Вердикт» на каждый файл.
