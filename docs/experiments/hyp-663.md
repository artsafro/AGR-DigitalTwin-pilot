## Verdict

**CONFIRMED** for this corpus: 0 changed scored fields on both real arms (threshold: any change) and on all 4 scored
synthetic controls, 0 exceptions, 0 omitted objects, 0 mutations, two identical repetitions. Both sensitivity
witnesses were exposed, so the comparison is not blind to the known rounding flips. This is evidence only for the
AC08 pilot-v010 readbacks; the constructed counterexamples in the research note still hold, and it does not show
the rounded predicate is correct elsewhere.
