# vpm.build — шаг карт D+ERM+N: что делает GeoAGR Render Material (L15, #1024)

Лаборатория AGR Tools 1.0, лот L15, ПК No_Defender, 3ds Max 2026, синтетика (Multi/Sub из 3 ID, UDIM 1001–1003).
Источник — Render Material ПКМ `GeoAGR.ms:22888-23415` (ЛКМ `:23417` для сравнения), хелперы `:1238-2514`,
`:3545-3558`. Доказательства — GeoAGR-private, ветка `lab-exp/10-L15`, `work/lab-experiments/vpm.build-maps/`
(`RESULT.md`, `VERDICT.json`, `runs/<job id>/`). Метки: **изм.** (job id), **стат.**, **гип.**

## Что измерено
- **изм.** `20261106-010845-vpm_main`: на каждый ID три файла `T_<имя>_{Diffuse|ERM|Normal}_1.<1000+ID>.png`,
  8 бит RGB без альфы; сцена и материал не меняются.
- **изм.** `…-010845-vpm_main`, `…-011038-vpm_channels`: у **PhysicalMaterial** Diffuse почти чёрный (среднее < 1
  из 255), ERM пустой; карта только в `metalness_map` не попадает в ERM. Standard работает.
- **изм.** `…-011038-vpm_channels`: ERM из отдельных карт Standard — G и B собраны, R (самосвечение) пуст; готовый
  упакованный ERM 256² копируется побайтно, **готовый ERM 512² не даёт ERM-файла вовсе**.
- **изм.** `…-011330-vpm_normal`: нормаль строится заново из слота bump (яркость → `normalmap.exe`); настоящая
  нормаль-карта не проходит как есть (отличие в среднем 35 уровней). Без bump — плоская, причём 127/127/255 при 512²
  и 128/128/255 при 256².
- **изм.** `…-010845-vpm_main`, `…-015734-vpm_texel_auto`: размер решают радиокнопки; карты-константы всегда 256²;
  автоподбор по тексельной плотности размера не меняет (обе ветки — 256²).
- **изм.** `…-011505-vpm_overwrite`: повторный запуск и смена размера молча перезаписывают все карты; PNG несёт время
  записи — выход не детерминирован.
- **изм.** `…-015558-vpm_renderer_lmb`: Arnold, Scanline и ART дают одинаковый набор. Corona и V-Ray —
  **не измерено: сторонний плагин** (в Max 2026 на ПК не установлены).
- **изм.** `…-010715-vpm_probe2`: коды выхода внешних программ не проверяются (успех при отсутствующем exe и входе);
  `normalmap.exe` пишет поверх входного файла; перевод цвета в HEX теряет ведущие нули
  (`GeoAGR.ms:1238-1249`: (5,128,255) → `#580ff`); путь к программам — только из `GeoAGR.ini`.

## Что известно статически
- **стат.** UDIM = ID + 1000 (`:22998`), слот в имени зашит `_1` (`:23016-23018`) — нет перенумерации библиотечных
  ID в плотные UDIM (К3).
- **стат.** ERM: R ← selfillum, G ← glossiness без инверсии, B ← reflect (`:23095-23101`); для Physical читается
  `reflectivity_map`, а не `metalness_map` (`:1500`); готовый ERM узнаётся по подстроке `_ERM_` в имени (`:23050`).
- **стат.** Карты строит только ветка Multi/Sub (`:22990`); одиночный материал — пусто (`:22974-22989`).

## Вердикт: `new`
Брать из GeoAGR только идею имени набора (через грамматику `names_core`). Не брать: ERM и нормаль из яркости и bump,
UDIM = ID + 1000, перезапись без вопроса, непроверяемые внешние программы. По #1024 ERM и нормаль берутся из записи
библиотеки материалов и маски серой карты (К3), UDIM — плотные из таблицы паспорта.

## Что меняется в требованиях
- `vpm.build`, шаг 6: явно запретить генерацию ERM и нормали из яркости/bump; источник — библиотека (`recipe`,
  `roughness`, `metallic`, маска).
- PhysicalMaterial — основной класс входа (Max 2026), Standard — совместимость.
- Политика перезаписи: новые файлы в папке результата или отказ при существующих, с отчётом.

## Минимальная приёмка
1. Мидпол с библиотечными ID {3, 7, 12, 31} (Physical, у одного карта только в `metalness_map`): ровно 3 файла на
   UDIM 1001..1004 подряд, имена по `names_core`, PNG детерминированы (повторный запуск — те же хэши).
2. ERM: R = emissive, G = roughness, B = metallic из записи библиотеки, ΔE каналов ≤ 1 уровня; металл не теряется.
3. Нормаль: из маски серой карты/библиотеки; поданная нормаль-карта проходит без изменений (хэш пикселей); без
   рельефа — плоская 128/128/255 при любом размере.
4. Diffuse у Physical по средней тела ≈ `base_color` (± 1 уровень).
5. Готовый ERM любого размера (256–4096) даёт ERM-файл.
6. Существующие файлы: отказ или новая папка, отчёт `skipped`; исходники — те же хэши.
7. Внешняя программа без exe или с ошибкой → `failed` в отчёте, без «успешного» пустого файла.
8. Одинаковый результат в Max 2024 и 2026; Corona/V-Ray только распознаются.
