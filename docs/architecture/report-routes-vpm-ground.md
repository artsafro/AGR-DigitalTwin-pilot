## ВПМ ОКС

15 стадий: исходники (Revit по `routes/revit-intake.md`) → PartsList → Gate 1 → корпус по частям (сразу ВПМ или
mid-poly мастер, D292) → проёмы и окна (библиотека с утоплением или генератор) → кровля, парапет, плита,
ограждение (R6) → декор, навесные элементы, разрезанный фасад → UV по UDIM → UCX (только ВПМ) → НПМ в тех же
координатах → export_meta и пакеты ВПМ / НПМ → свежее чтение экспорта → проверки / xView → СИНТЕЗ → сдано.
Стадии 4–8 и 10 делает агент там, где удобно: Blender, Max, AGR Tools [D293].

## Ground

14 стадий, целевой порядок [D293]: DWG / ПЗУ / PDF / 3D-рельеф → граница и ноль (из проекта или агент уточняет) → плоский Ground:
покрытия по штриховкам → ID → треугольники, швы и вставки → текстуры по ID (бесшовные острова, тайлы UDIM подряд с 1001 [D399])
→ проекция плоского Ground на рельеф → правка текстур и юбка ≥ 1 м → UCX (только ВПМ) → расстановка МАФ / Флоры
→ НПМ в координатах (МАФ и Флора НПМ на атласе, Ground на атласе) → экспорт НПМ / ВПМ → упаковка → проверки →
СИНТЕЗ. Та же поверхность Ground с разной развёрткой — требование D293, не вывод из числа треугольников v015.

- `legend-intake` — `agr inspect` читает манифест; [инвентарь DXF](../../tools/source/inspect_ground_dxf.py) помогает, но не сверяет легенду.

  белая разметка на стыках — вне команды.
- `project-zero` — `agr zero` проверяет Z в OBJ по заданному нулю, а не определяет отметку; система высот КПП1 / ТЭЦ26 — unknown.

Только для Ватутино v015: D157 (≤ 35 % остаточных треугольников) и маршрут A (D193). D192 заменено D157 и сохранено только как историческая справка.
- `flat-uv` — UV / UDIM назначает `ground_site` до проекции, без файлов текстур и атласа.
- `steep-step` — ступень 80° Ватутино: обрыв TIN у подпорной стены без геометрии; исключения D150 / D191.
- `skirt-gap` — 20 рёбер v015 с опуском 0 на крутой полосе 80°; `agr ground site` считает опуск каждого внешнего
  ребра (`skirt_gap_edges`); v015 не правится.

- `obj-to-ucx` — `agr ucx` принимает FBX / Blend, не OBJ.

- `budget` — НПМ 166 336 из 180 000 (GND-04), ВПМ Флора 443 788; делит Артём (D167).
