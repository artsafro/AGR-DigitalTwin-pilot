Что изменилось в v2 [D293]:

1. Шаги не привязаны к инструменту: корпус по частям, проёмы, кровля / парапет / ограждение, декор, UV, проекция
   Ground — исполнитель «Агент: Blender / Max / AGR Tools». AGR Tools / скрипты Max — идеал для ручного режима
   Артёма, не требование к агенту.

   ВПМ → НПМ (`agr vpm-to-npm`) или параллельная работа. На экспорте оба упаковщика (`agr package-vpm`,
   `agr package-npm`).
3. Ground: исходники DWG, ПЗУ, PDF и, если есть, 3D-рельеф; граница и ноль — из проекта или агент уточняет.
   Рельеф — последним: сначала плоский Ground (ID, треугольники / швы / вставки, текстуры по ID), потом проекция
   на рельеф, правка текстур и юбка, UCX, МАФ + Флора, НПМ, экспорт, проверки, чекер.
4. Две новые карты контекстов (ВПМ ОКС и Ground) — тем же генератором; дубли в них описательные, охранный список
   `duplicate_guard` остаётся в `contexts.yaml`.

## ВПМ ОКС

15 стадий: исходники (Revit по `routes/revit-intake.md`) → PartsList → Gate 1 → корпус по частям (сразу ВПМ или
mid-poly мастер, D292) → проёмы и окна (библиотека с утоплением или генератор) → кровля, парапет, плита,
ограждение (R6) → декор, навесные элементы, разрезанный фасад → UV по UDIM → UCX (только ВПМ) → НПМ в тех же
координатах → export_meta и пакеты ВПМ / НПМ → свежее чтение экспорта → проверки / xView → СИНТЕЗ → сдано.
Стадии 4–8 и 10 делает агент там, где удобно: Blender, Max, AGR Tools [D293].

## Ground

13 стадий: DWG / ПЗУ / PDF / 3D-рельеф → граница и ноль (из проекта или агент уточняет) → плоский Ground:
покрытия по штриховкам → ID → треугольники, швы и вставки → текстуры по ID (бесшовные острова, тайлы, UDIM = ID)
→ проекция плоского Ground на рельеф → правка текстур и юбка ≥ 1 м → UCX (только ВПМ) → расстановка МАФ / Флоры
→ НПМ в координатах (МАФ и Флора НПМ на атласе, Ground на атласе) → экспорт НПМ / ВПМ и пакеты → проверки →
СИНТЕЗ [D293]. Геометрия Ground в ВПМ и НПМ одна; отличаются только атлас и развёртка UDIM.

### Стадии без команды agr / dt

| Стадия | Статус | Чем делают сейчас |
|---|---|---|
| `zero` | `agr zero` / `dt ground zero` (#1406) | `h_relief` = ноль проекта (D279) и проверка Z экспорта против диапазона рельефа |
| `surfaces` … `skirt` | `agr ground site` / `dt ground site` (#1406) | один спец-файл участка: штриховки → ID (цвет = фон штриховки), плоский Ground, UDIM = ID, проекция, юбка ≥ 1 м |
| `ucx` | нет команды | UCX собраны в DCC отдельно, `assemble_delivery.py` берёт их из C:/x |
| `placement` | нет команды | движок `dt_ai.placement` вызывается из `jobs/VATUTINO-SITE/place_site.py` |

`agr ground site` / `dt ground site` (#1406) собирает любой участок в порядке D293 из спец-файла (DXF + sha256,
граница, ноль с источником, покрытия, рельеф); проверено на Силикатном (#1315, фрагмент D283). `agr ground` без шага
и `dt ground v015` — замороженная запись Ватутино v015, не менялась. UCX — `not_run`, владелец доработка 7 (#1404).
