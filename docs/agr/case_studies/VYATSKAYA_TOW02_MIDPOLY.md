- Mid-poly мастер башни TOW02 из сцены Blender (исходник из 3ds Max, панельный curtain wall, 604k треугольников
  фасада), затем текстура OKS 013 [D156] и NPM.

  QA только Overlapping Faces 5 мм / Overlapping Vertices 2 мм, overlap'ы чинить смещением, не удалением.

## Что сработало и что пришлось исправить
- Сработало: прямая сборка «Lego» по замерам (кольца корпуса → плоскости проёмов → декор → верх) вместо движка;
  чистка стекла (плоское окно = 1 quad); атлас из полос окон источника (31 полоса, 77.25 px/m); F8 исправлен в
  генераторе корпуса (`build_stack`, «скользящие стены») с перепрогоном цепочки от build-v013.
- Не сработало: движок (`dt spec extract`) на панельном источнике — ~1.5 ч впустую; собственная проверка overlap'ов в
  Blender — сказала 0, а xView при 5 мм нашёл 185 граней (независимая проверка — 23 пары).
- Пользователь доделал руками: недорезанная геометрия и лишние рёбра на верхних этажах (там overlap'ы); стеклянные
  ограждения балконов переделаны; текстура чуть переразвёрнута, цвета изменены.
- Неизвестно: точный список правок пользователя по граням — сравнение в задаче-разборе.
