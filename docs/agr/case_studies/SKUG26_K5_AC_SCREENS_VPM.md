## Что сработало и что пришлось исправить
- Сработало: счёт отверстий по эйлеровой характеристике элемента пластины (χ = 2 − 2h) и кластеризация вершин в
  Python по выгрузке одной пластины; фаза поля отверстий снята по каждому из 126 элементов (44 зеркальных).
- Одинаковые панели сложены стопкой на 4 острова в тайле 1004 (тайл = ID, как в сцене); тексель ровно 1300.
- Исправлено:
  - цикл `getFacesUsingVert` по вершинам меша на 4,3 млн граней повесил Max (пользователь закрыл его);
  - `detachFaces delete:true` перенумеровал грани — удалились не те, `max undo` через MCP не откатил,
    `loadMaxFile` через MCP уронил Max; v002 на диске не пострадал, Object004/005 отделены заново;
  - в MAXScript `n` и `N` — одно имя (деление на нормаль); `i` затенял `I`;
  - дыры только в альфе не видны на бежевой стене — добавлен тёмный RGB в дырах.
- Не проверено: просвет по cutout в рендере, экспорт FBX, именование по регламенту.
