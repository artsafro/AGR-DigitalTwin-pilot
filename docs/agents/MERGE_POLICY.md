# Политика мёржа (кратко для Артёма)

Один файл правил: `docs/agents/MERGE_POLICY.yaml` (#2038). Классификатор `tools/merge_policy.py` только читает
GitHub и пишет журнал; права мёржа у него нет. Режим сейчас — **наблюдение**: журнал
`C:/x/merge-policy-observe/decisions.jsonl` показывает, куда попал бы каждый открытый PR; ничего не вливается.

## Три корзины

| Корзина | Что | Основание |
|---|---|---|
| `auto` — вливается само после CLEAN-ревью на текущем коммите | исправление красного main (ветка `fix/red-main-*`, одно, правило 74); очередь гигиены (`kpi/hygiene_autoqueue.json`); только research/experiments/decisions/measurements; малый PR (≤ 200 строк, без защищённых путей, без вашего решения в карточке) | ваши слова ниже |
| `artem` — только по вашему слову («Мерджи #N») | меняет сданную модель / геометрию / текстуры / принятые файлы / библиотеку; меняет порядок работы агентов (хуки, скелеты, правила ревью, AGENTS.md, `docs/agents/`, маршруты); в карточке было ваше решение; рабочий код больше 200 строк; всё, что не покрыто согласием | D234, правило 75 |
| `never` — автоматика не вливает никогда | `.github/`, `data/`, `standards/`, `benchmark/` | матрица прав (WORKFLOW), список PROTECTED в agr_automerge |

Правила проверяются сверху вниз, первое совпадение решает (порядок — в YAML). Кроме путей есть
текстовые классификаторы («меняет сданную модель», «меняет, как работают агенты»): они цитируют
найденную фразу и пропускают фразы с отрицанием («No accepted file changed»).

## Условия для ЛЮБОГО мёржа
main зелёный (нет `STOP_AUTOMERGE`; кроме самого исправления красного main) · база = main (PR поверх
другой ветки — отказ с названием базы) · не черновик · MERGEABLE · последнее ревью CLEAN (P1 = 0) на текущем
коммите · ревьюер-профиль ≠ автор-профиль.

## Команды
```
uv run python tools/merge_policy.py classify --pr 2033        # корзина + причины + невыполненные условия
uv run python tools/merge_policy.py observe                   # журнал по всем открытым PR
uv run python tools/merge_policy.py backtest --limit 10       # сверка с тем, как PR влились на деле
```
Включить реальный автомёрж по этой политике можно только вашим словом (вне #2038).
Заметка «что изменил / зачем / как откатить» для автоматических пушей: `docs/agents/STEWARD_NOTE.md`.
