# Черновики типов окон

Здесь лежат проверенные черновики записей типов окон. Черновик — это запись для проёма, у которого ещё нет типа в библиотеке.

Правило D116: агент и `win.place` предлагают только черновик. В библиотеку он попадает только через лист превью «было → стало» и `confirmations.json`.

## Схема `window-type-draft/1`

Запись строит `draft_entry` в `adapters/max/agr_tools/windowgen_core.py`. Поля:

- `schema` — `window-type-draft/1`;
- `status` — `draft`;
- `id` — `null`, id выдаётся при принятии в библиотеку;
- `name` — имя типа или `null`;
- `role` — роль (по умолчанию `window`);
- `width_m`, `height_m` — размер проёма в метрах;
- `sections`, `transoms` — число секций и импостов (черновик: 1 и 0);
- `panes_m` — одно поле стекла внутри лица рамы семейства: `[[f, f, w - f, h - f]]`;
- `opaque_m` — глухие поля, в черновике `null`;
- `family` — семейство стандарта (F100 для окна);
- `source` — откуда взят проём: `opening`, `wall`, `kind`, `why`.

## Откуда берутся файлы

`win.place` в режиме apply пишет черновики новыми файлами `draft_OPEN_<nnn>.json`. Существующий файл не перезаписывается: берётся следующий свободный `_vNNN`.

Папка задаётся `options.drafts_dir`. По умолчанию это `window_drafts` рядом со сценой. Для несохранённой сцены — `%LOCALAPPDATA%\AGRTools\window_drafts`.

В эту папку репозитория черновики попадают только вручную, после просмотра.
