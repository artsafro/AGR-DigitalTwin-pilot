## Window-agent brief: new builds only [D322]

- Glass and grille panels are single planes at **real frame mid-depth**, with **15-20 mm per-edge
  cover under the frame** (default 20 mm). `fields` remain the clear lights, not enlarged panel bounds.
  `build_type(..., {'infill_overlap_m': 0.017})` may preserve a measured cover in that range.
- Supply `entry.frame_profile_m` from the Revit type: `face_m`, `depth_m`, `impost_m`;
  optional `face_top_m`/`face_bottom_m`. Never infer it from decorative material colour.
  Without source dimensions use the family profile (faces 54-65 mm, about 50-70 mm), not thin strips.
- Request a visible-through-glass interior explicitly via
  `{'interior': {'setback_m': <source seat behind frame>, 'depth_m': <source room depth>}}`.
  It is an independent **open-front box**, opening outline +44 mm on each side and +130 mm at
  head/sill, with inward faces and its own capsule material/part. It never extrudes frame edges.
  Room depth is not guessed. No interior is generated by default in clean reusable library assets.
- `grilles_m` uses the same rectangle format as `panes_m`. **No capsule behind a ventilation grille**;
  requesting one fails. Split mixed glass/grille openings before requesting an interior. Ask before
  removing an existing capsule: this generator creates new meshes, it does not edit old scenes.
- Keep glass separate: `part_mesh(mesh, 'glass')`, OBJ object/group `<id>_glass`, and separate
  Max glass masters/instances. `body` contains non-glass parts without dropping grilles. At delivery
  collect main glazing into the profile's `*_MainGlass` object; do not Attach it to the facade.
  NPM opaque-atlas planes are unchanged; this is not a waiver of profile/material/export gates.
