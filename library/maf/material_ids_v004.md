## Atlases: how they are made

Concept (Artem 2026-10-21): MAFs are textured through atlases for both profiles - VPM: a 4K map per UDIM tile; NPM: 2K maps named GroundEl, laid out the same way; a site set is 512 px (MAF-09). Cells are found by guillotine cuts + flat-block detection (`tools/library/maf_atlas_cells.py`); cell -> id is a colour-distance match only (`dist`, mean |dRGB|), not a visual check - verify on the contact sheet and overlays.
