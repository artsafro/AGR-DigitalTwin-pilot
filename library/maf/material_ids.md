# MAF library material IDs

Active list: [`material_ids_v005.json`](material_ids_v005.json) (approved-v1, 2026-10-22 [D181]).
`material_ids.json` is a pointer at that file and its sha256. Nothing is reassigned in the library scenes.

v005 is the first working version. Corrections only from project use, and each change is a new version with a changelog line. Items still marked «на проверку» stay flagged (HDPE container on id 10, HPL «атласное дерево» on id 14). The human-readable twin is [`material_ids_v005.md`](material_ids_v005.md).

The older v003 proposal was generated by `tools/library/maf_material_ids.py`. That generator still builds a candidate list from library FBX materials; do not write its output over `material_ids.json`.
