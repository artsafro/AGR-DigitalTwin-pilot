### 3.2 Типовые процедурные серые плитки (b)

**Ограничение (зафиксировано, ответы Артёма 06.11):** шаг UDIM 3,6 м, кратно модулям 1,2 и 0,6 м ([D207]). VPM-норматив: 512–1706 px/м, 4096² или 2048², отступ ≥32 px на 4096 (`docs/domain/uv-textures.md:27-31,52`).

**Расчёт (вывод):**

* 3,6 м × 1024 px/м = **3686,4 px — нецелое**. Ни один модуль, делящий 3,6 м (0,6 → 614,4; 1,2 → 1228,8; 0,3 → 307,2; 0,1 → 102,4), не даёт целого числа пикселей. Периодичность тайла придётся держать на 3686 px (≈1023,9 px/м) с ошибкой <0,01 %, либо
* при **1000 px/м** 3,6 м = **3600 px**: все модули целые (0,05 → 50, 0,075 → 75, 0,1 → 100, 0,3 → 300, 0,6 → 600, 1,2 → 1200), поле 4096 даёт 248 px отступа с каждой стороны (≥32 ✓). 1000 px/м — уже плотность KPP1/PSU275 (`KPP1/REPORT.md:33`) и укладывается в 512–1706. Либо 4096/3,6 = **1137,8 px/м** — тоже в норме.

→ рекомендую **1000 px/м** и содержимое 3600 px (вопрос Q1). Если Артём настаивает на 1024 — допустима сборка на 3686 px с проверкой фазы швов на границе тайла.

**Что из найденных модулей делится на 3,6 м:**

| Модуль | Где | N на 3,6 м | Годится |
|---|---|---|---|
| 0,6 | кассета X, плитка | 6 | да |
| 1,2 | сэндвич (PSU 1,19 → 1,2: +0,8 %) | 3 | да |
| 0,3 | цоколь, шов плиты | 12 | да |
| 0,1×0,3 (шов внутри модуля) | брусчатка | 36×12 | да, но **шаг 105×305 (шов снаружи) — нет** |
| 0,9×0,3 | плита шаговая, ограждение | 4×12 | да |
| 0,075 | кирпич по высоте (ряд 65+10) | 48 | да |
| 0,26 | кирпич по длине (250+10) | 13,85 | **нет** → 14 шт = 0,2571 (−1,1 %) |
| 0,605×1,205 | плитка при шве снаружи | 5,95×2,99 | **нет** → модуль 0,6×1,2 со швом внутри |
| 0,55 | ряды кассеты KPP1 | 6,55 | **нет** → 0,6 или 0,45 |

### 3.3 Что общего с MAF v005 (c)

* MAF v005 — **31 активный ID** (`material_ids_v005.md:9-39`): 13 красок RAL (S), 6 дерево, 2 металл, пластик, резина, 3 минерал, 3 opacity (сетка, перфорация, канат), профнастил, поликарбонат. Утверждён как первая рабочая версия, правки только по опыту проектов (`:3`).
* **Общие цвета**: ОКС RAL **5015** = MAF ID 11; **7047** = ID 4; **3020** = ID 7; **7016** = ID 2; **7004** сведён в ID 3 (7040/7004; `Merged`: 7004 ≈ 7040, |dRGB|~4); **9016** — только близкий ID 5 (9003/9002), точного нет. **Нет в MAF:** RAL **1021**, **7024**, **8023**, **9006**, **7035** — все из ОКС/фасадов.
* **Схема**: ключ (`paint_ral7047`), kind (paint/wood/metal/plastic/rubber/mineral/opacity/sheet/translucent), класс размера S/M/L, target RGB, статус approved-v1. В таблицу ОКС целесообразно взять тот же набор полей; kind дополнить `panel`, `tile`, `brick`, `paving`, `ground`, `roof`, `glass`, `interior`.
* **Один источник цвета**: `tools/materials/ral_classic.json` (34 RAL) уже используется и Ground, и MAF-атласом (`site-maf-set.md:54`). RGB KPP совпадают с ним для 5015 (#2271B3), 7004 (#969992), 7047 (#D0D0D0), 9016 (#F6F6F6), 3020 (#CC0605). **Расхождение:** RAL 1021 в KPP/PSU/AC04 = (238,201,0), в `ral_classic.json:1021` = #F6B600 (246,182,0); 7024 в ОКС-реестре Revit = #45494E, в таблице #474A51 (Q9).
* **MAF-атлас не покрывает плитки/панели**: 9 из 31 ID без ячейки атласа (`gap: no atlas cell`: ID 18, 21, 23–26, 28, 29, 31). Повторное использование MAF-материалов — только для малых форм и общих красок.
* **Обратное**: MAF-таблица знает 6 деревянных и 3 металлических ID, которых нет ни в одном ОКС (используются только в MAF ландшафта). В таблице ОКС они даны как 4 `proposal`-строки (WOD-02, MET-04, GRD-07, ROF-03) — можно убрать, если ОКС 1.0 не включает малые формы.

## 4. Что говорит регламент о материалах (для таблицы)

* Только Standard (Legacy)/Physical/Principled; PBR через доп. карты (`docs/domain/materials.md:5-6`).
* NPM: стекло — до 7 материалов `M_Glass_01..07`, α=0,5 (`:8-9`). Число непрозрачных материалов = числу наборов текстур (`:10`).
* VPM: до 7 материалов на объект, Main — один слот до 100 UDIM; глянцевое стекло — отдельный меш (`:14-17`). По ответу Артёма (В9) нумерация UDIM **отдельно в каждом меше**, тело ОКС с 1001, окна/стекло — отдельный меш, тоже с 1001 ([D209]).
* Заглушки 256² без альфа — только для гладких поверхностей, **запрещены для кирпича/плитки** (`uv-textures.md:37`): значит все `TIL`, `BRK`, `PAN`, `PAV` — полноценные 4096.
