## `omk_um.tsv` — улицы Москвы

- **Первичный источник.** Портал открытых данных Правительства Москвы data.mos.ru, набор «Общемосковский классификатор
  улиц Москвы (ОМК УМ)». Поля набора: `UM_NAMEF`, `UM_NAMES`, `UM_CODE`, `UM_TRANS`, `UM_TYPE`, `UM_TM`, `UM_TE`,
  `UM_KLADR`, `global_id`. Открытые данные data.mos.ru можно использовать свободно, со ссылкой на источник.
- **Как получен.** С ноутбука data.mos.ru недоступен (таймаут, 05.11.2026). Взята выгрузка этого набора из пакета
  заказчика SINTEZ AGR Checker 1.6.1 (Blender extension, SINTEZ.SPACE, `license = SPDX:GPL-3.0-or-later`):
  `documents/lp_codes.xlsx`, SHA256 `65b314ce5a94b7a8b27d16fe2928b1934383002b755e07ac5a0246d8a4eef66f`, копия
  в `%APPDATA%/Blender Foundation/Blender/5.1/extensions/user_default/sintez_agr_checker/` на ноутбуке Артёма.
  Это тот же маршрут, что у реестра ФНО в 0.8.1 (`standards/data/fno_codes.PROVENANCE.md`).
- **Что сделано.** Из листа взяты 5 колонок: `global_id`, `UM_CODE` → `um_code`, `UM_TYPE` → `um_type`,
  `UM_NAMEF` → `name`, `UM_TRANS` → `trans`. Вторая строка шапки (русские подписи) отброшена. Пробелы схлопнуты,
  строки отсортированы по `name`, `um_code`, `global_id`. Значения не менялись.
- **Как используется.** `trans` — транслитерация ГОСТ 7.79-2000 (система Б) из самого классификатора. Ядро убирает
  знаки `` ` `` и `'`, пишет слова с заглавной и слитно, тип улицы сокращает по Приказу Минфина № 171н («улица»
  опускается, «проезд» → `Prd`, «переулок» → `Per`…). Ту же форму принимает GeoAGR (`ul5.csv`, лаборатория L05:
  `Tverskaya_7`, `PervyjAvtozavodskijPrd_7`). Числительное принимается и словом, и цифрой (`2jKotelnicheskijPer`).
  26 проектируемых проездов с «№» в названии одного элемента Address не имеют и пропускаются (`count.skipped`).

## `settlements_wikidata.tsv` — поселения в границах Москвы

- **Источник.** Wikidata, лицензия CC0. Запрос SPARQL 05.11.2026 11:01 UTC (`query.wikidata.org`): элементы с
  `P31` ∈ {деревня Q5084, посёлок Q2514025, село Q532, хутор Q2023000, посёлок городского типа Q2989457, город Q7930989,
  исторический район Q15243209}, у которых `P131` (до трёх уровней) — Москва Q649, с русской подписью.
- **Колонки.** `qid`, `kind` (русское имя типа), `name` (подпись `ru`).
- **Как используется.** Имя транслитерируется по ГОСТ 7.79-Б (как `UM_TRANS`); уточнение в скобках и тип в начале
  подписи отбрасываются. Принимаются форма без префикса и с префиксом типа по 171н (`PosAkulovo`, `DAkulovo`, …).
- **Полнота.** 330 записей — не полный реестр поселений Новой Москвы. Неизвестное поселение даёт
  `addr_street_unknown`: дополните справочник, а не правило.
