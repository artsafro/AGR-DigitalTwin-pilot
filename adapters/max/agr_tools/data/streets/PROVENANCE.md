# data/streets — справочник улиц для `qa.address`

Владелец: ветка **C** (`improve/issue-979-qa`, #979). Пустая заглушка ветки 0.

Ветка C кладёт сюда справочник улиц и записывает в этот файл:

- источник (откуда взят список, дата, лицензия/разрешение);
- SHA256 каждого файла папки;
- как обновлять.

Справочники GeoAGR (CSV) не копируются (#853): только ссылка `GeoAGR.ms:<строка>`.
Папка ставится в пакет целиком (`tools/max/build_agr_tools.py`, `data/`), глубина — не больше одной подпапки.
