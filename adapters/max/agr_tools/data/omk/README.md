# Таблица ОМК ТЭ (qa.omk_te)

В пакете **нет** таблицы кодов и нет копии справочника GeoAGR (ответ Артёма 06.11.2026). Путь к таблице —
параметр `table` кнопки.

Формат файла пользователя: UTF-8 (BOM допустим) или UTF-16 с BOM; разделитель — табуляция; первая строка —
заголовок `place<TAB>code`; одна ячейка — один код из цифр (`905` хранится как `0905`). Строки с пустым местом/кодом,
несколькими кодами в ячейке и не-цифровым кодом попадают в отчёт, молча не записываются.
